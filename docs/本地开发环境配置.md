# ERP 企业管理平台 · 本地开发环境配置指南

本指南面向 **Windows 本地开发**，采用**本机安装 MySQL + Redis + Nacos + IDEA 直跑微服务 + 前端 npm run dev** 的方式运行。
（Docker 部署如需支持请另行补充。）

---

## 一、技术栈与版本（对应当前仓库）

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17+（本项目验证使用 JDK 24） | 均可编译运行 |
| Spring Boot | 4.1.0 | 见根 pom `<spring-boot.version>` |
| Spring Cloud | 2025.1.2 | 见根 pom `<spring-cloud.version>` |
| Spring Cloud Alibaba | 2025.1.0.0 | 对应 Nacos 客户端 3.x |
| Nacos Server | 3.0.2 | 推荐 3.x；2.x 与 2025.1 客户端不兼容 |
| MySQL | 8.0+（端口 3306） | 5.7+ 亦可 |
| Redis | 6+（端口 6379） | 无密码 |
| Maven | 3.9.16 | 也可用其他 3.9+ |
| Node / npm | 20 / 10 | 前端 Vue2 + vue-cli |

### 模块端口一览（ERP 微服务为 9217-9223）

| 模块 | 端口 | 模块 | 端口 |
|---|---|---|---|
| ruoyi-gateway（网关） | 8000 | ruoyi-modules/gen | 9202 |
| ruoyi-auth（认证中心） | 9200 | ruoyi-modules/job | 9203 |
| ruoyi-modules/system | 9201 | ruoyi-modules/file | 9300 |
| ruoyi-visual/monitor | 9100 | 前端 dev-server | 80（被占用回退 8081） |
| **ruoyi-modules-erp-base** | **9217** | **ruoyi-modules-erp-finance** | **9221** |
| **ruoyi-modules-erp-purchase** | **9218** | **ruoyi-modules-erp-production** | **9222** |
| **ruoyi-modules-erp-sale** | **9219** | **ruoyi-modules-erp-report** | **9223** |
| **ruoyi-modules-erp-stock** | **9220** | | |

> **端口占用说明**：RuoYi 默认模块占用 9200-9203 / 9300 / 9100；外部 OA 微服务（approval/todo/calendar/contacts/portal）占用 **9210-9214**。ERP 业务微服务因此安排在 **9217-9223** 空闲段，避免冲突。

基础设施端口：MySQL `3306`、Redis `6379`、Nacos 主端口 `8848`（gRPC `9848/9849`、Jraft `7848`）、Nacos 控制台 `18088`。

> **为什么用 8000 而非 8080**：Windows 系统保留端口段 `8028-8127` 内任何进程都无法绑定（报 “Address already in use”），默认 `8080` 恰在此段内，故本项目统一改为 `8000`（`ruoyi-gateway/bootstrap.yml`、`vue.config.js` 及 Nacos 网关配置已同步）。Linux 无此限制，可改回 8080。

## 二、首次初始化数据库（一次性）

仓库 `sql/` 下的脚本为**本地版**（`localhost`/`127.0.0.1`、Windows 路径），适合本机直接使用。

### 1. 确认本机 MySQL 账号

数据库账号为 `root / 密码`，与本地一致；若 root 密码**非空**，需到 Nacos 控制台把对应 `ruoyi-*-dev.yml` 的 `password:` 改成你的密码并发布。

```powershell
mysql -h 127.0.0.1 -P 3306 -uroot
```

### 2. 建业务库 `ry-cloud`

```powershell
mysql -h 127.0.0.1 -P 3306 -uroot -e "CREATE DATABASE IF NOT EXISTS `ry-cloud` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
```

### 3. 导入业务表（基础表 + 定时任务 + ERP 业务表）

```powershell
mysql -h 127.0.0.1 -P 3306 -uroot --default-character-set=utf8mb4 ry-cloud < sql\ry_20260417.sql
mysql -h 127.0.0.1 -P 3306 -uroot --default-character-set=utf8mb4 ry-cloud < sql\quartz.sql
mysql -h 127.0.0.1 -P 3306 -uroot --default-character-set=utf8mb4 ry-cloud < sql\ry_erp_20260818.sql
mysql -h 127.0.0.1 -P 3306 -uroot --default-character-set=utf8mb4 ry-cloud < sql\ry_erp_20260819.sql
```

> `ry_erp_20260818.sql`：ERP 业务表 DDL + 菜单（基础资料 2070-2074、采购/销售/库存/财务/生产 2010-2052）+ ERP 字典。
> `ry_erp_20260819.sql`：报表中心菜单 2060-2064 + 角色授权（普通角色 role_id=2）。
> 另有 `sql/ry_erp_ai_20260819.sql`（智能助手菜单 2080/2081）与 `sql/ry_erp_seed_20260819.sql`（演示种子数据），建议一并导入：

```powershell
mysql -h 127.0.0.1 -P 3306 -uroot --default-character-set=utf8mb4 ry-cloud < sql\ry_erp_ai_20260819.sql
mysql -h 127.0.0.1 -P 3306 -uroot --default-character-set=utf8mb4 ry-cloud < sql\ry_erp_seed_20260819.sql
```

> 若 `ry-cloud` 已存在旧项目（如 OA-demo）占用的菜单 ID（2000-2004 等）与 ERP 冲突，导入时可能报主键冲突，可用 `mysql ... --force` 强制继续，或手工调整菜单 ID。

### 4. 导入配置库 `ry-config`（Nacos 配置）

```powershell
mysql -h 127.0.0.1 -P 3306 -uroot < sql\ry_config_20260611.sql
```

该脚本自带 `CREATE DATABASE ry-config` + Nacos 3.x 表结构（`config_info`、`users` 等）+ 基础配置，执行一次即可。

### 5. 验证

```powershell
mysql -h 127.0.0.1 -P 3306 -uroot -e "SELECT COUNT(*) AS biz_tables FROM information_schema.tables WHERE table_schema='ry-cloud'; SELECT COUNT(*) AS cfg_cnt FROM ry-config.config_info;"
```

预期：业务表 `20+`（含 ERP 表）；配置 `9+` 条 data_id。

> 说明：仓库 `nacos/` 目录保存了各服务的配置 yml 参考文件（含 ERP 拆分后的 `ruoyi-erp-{域}-dev.yml`）。运行时 Nacos 读取的是**服务端存储**的配置；若服务端缺失/过期，需把 `nacos/` 下的 yml 发布到 Nacos 控制台（或直接改 `ry-config.config_info`）。ERP 拆分后新增了 7 个 data_id：`ruoyi-erp-{base|purchase|sale|stock|finance|production|report}-dev.yml`。

## 三、安装并启动 Nacos 3.0.2（一次性）

### 1. 下载解压

从 https://nacos.io/download/nacos-server/ 下载 **nacos-server-3.0.2.zip**，解压到**不含中文空格**路径（如 `D:\env\nacos-server-3.0.2`）。

> 版本说明：`sql/ry_config_20260611.sql` 表结构与 Nacos 3.0.x 对应；3.1/3.2 亦可，但需确认 schema 兼容；**不要用 2.x**。

### 2. 修改 `conf\application.properties`

```properties
# 控制台端口（默认 8080，与网关撞了，改成 18088）
nacos.console.port=18088
# 注意：不要手动设 server.port，3.x 会按 nacos.console.port 自动推导避免端口冲突

# 连接本机 MySQL（ry-config 库）
spring.datasource.platform=mysql
db.num=1
db.url.0=jdbc:mysql://127.0.0.1:3306/ry-config?characterEncoding=utf8&connectTimeout=1000&socketTimeout=3000&autoReconnect=true&useUnicode=true&useSSL=false&serverTimezone=UTC
db.user.0=root
db.password.0=

# 本地开发关闭控制台鉴权（更简单）
nacos.core.auth.enabled=false
nacos.core.auth.plugin.nacos.token.secret.key=<任取 32 位以上字符串做 Base64，如 VGhpc0lzTXlDdXN0b21TZWNyZXRLZXkwMTIzNDU2Nzg=>
nacos.core.auth.server.identity.key=serverIdentity
nacos.core.auth.server.identity.value=security
```

> 不同 3.x 小版本键名可能不同，以 `conf/application.properties` 注释为准。

### 3. 启动单机模式

```powershell
cd D:\env\nacos-server-3.0.2\bin
startup.cmd -m standalone
```

需要 `JAVA_HOME` 指向 JDK 17+（24 亦可）。

### 4. 验证

- 日志出现 `Nacos started successfully in stand alone mode.`
- 控制台 http://127.0.0.1:18088（鉴权已关，可直接进入）
- 「配置管理」应能看到全部 data_id；「服务管理」应能看到各微服务实例。

## 四、关键配置速查（改动后需生效）

配置统一存放在 Nacos（`ry-config.config_info`），可按需选择：**控制台直接改** / **直接改 SQL 再重启** / **用 `nacos/` 目录参考文件 + 控制台发布**。

| 要改的东西 | 位置 | 当前值（本地版） |
|---|---|---|
| 数据库账号密码 | 每个 `ruoyi-*-dev.yml` 的 `datasource.url / username / password` | `root / 空`；url 为 `localhost:3306/ry-cloud` |
| Redis | 每个 `ruoyi-*-dev.yml` 的 `spring.data.redis` | `localhost:6379`，无密码 |
| 文件上传目录 | `ruoyi-file-dev.yml` 的 `file.path` | `D:/ruoyi/uploadPath`（Windows 本地，首次上传自动建目录） |
| Nacos 地址 | 各模块 `bootstrap.yml` 的 `server-addr` | `127.0.0.1:8848`（本机不用改） |
| 服务端口 | 各模块 `bootstrap.yml` 的 `server.port` | 见第一节端口表 |
| ERP mybatis 别名 | 各 `ruoyi-erp-{域}-dev.yml` 的 `mybatis.typeAliasesPackage` | `com.ruoyi.erp.{域}` |

> 改动 Nacos 配置后若未生效：确认控制台 group 为 `DEFAULT_GROUP`；部分模块（尤其网关路由）改动后建议**重启对应服务**。

## 五、IDEA 启动微服务

### 1. 导入工程

File → Open 选择根目录 `pom.xml`，以 Maven 工程打开，等待依赖下载完成。

### 2. 设置 JDK 与 Lombok

- File → Project Structure → Project SDK 选 JDK 17（或 24），Language level 选 17。
- Settings → Build, Execution, Deployment → Compiler → Annotation Processors → 勾选 **Enable annotation processing**（否则 Lombok 报错）。

### 3. 配置 Maven

Settings → Build Tools → Maven → Maven home path 填 `D:\Program Files\apache-maven-3.9.16`（或你的安装路径）。

### 4. 首次构建公共模块

在项目根目录执行，把 `ruoyi-common*` 等安装到本地仓库（**首次必需**）：

```powershell
mvn clean install -DskipTests
```

### 5. 启动微服务（建议顺序）

每个模块都有对应 `Application` 类，IDEA 直接 Run 即可。**先启动基础设施依赖**（Nacos、Redis、MySQL），再按下列顺序：

1. `ruoyi-gateway`（RuoYiGatewayApplication，8000）
2. `ruoyi-auth`（RuoYiAuthApplication，9200）
3. `ruoyi-modules/ruoyi-system`（RuoYiSystemApplication，9201）
4. （可选）`ruoyi-modules/gen`（9202）、`ruoyi-modules/job`（9203）、`ruoyi-modules/file`（9300）、`ruoyi-visual/ruoyi-monitor`（9100）
5. **ERP 业务微服务（7 个）**：
   - `ruoyi-modules/ruoyi-erp-base` → RuoYiBaseApplication（9217）
   - `ruoyi-modules/ruoyi-erp-purchase` → RuoYiPurchaseApplication（9218）
   - `ruoyi-modules/ruoyi-erp-sale` → RuoYiSaleApplication（9219）
   - `ruoyi-modules/ruoyi-erp-stock` → RuoYiStockApplication（9220）
   - `ruoyi-modules/ruoyi-erp-finance` → RuoYiFinanceApplication（9221）
   - `ruoyi-modules/ruoyi-erp-production` → RuoYiProductionApplication（9222）
   - `ruoyi-modules/ruoyi-erp-report` → RuoYiReportApplication（9223，含工作台待办）

顺序非强制（都注册到 Nacos 即可），建议先把 gateway/auth/system 起来，再起 ERP 服务。每个模块控制台出现 `Started ... Application in xx seconds` 即 OK；可在 Nacos 控制台「服务管理」确认实例已注册。

### 6. 验证网关

访问 `http://localhost:8000`，未登录会跳转登录页并提示认证异常（正常）。随后按第六节启动前端登录。

## 七、常见问题（FAQ）

1. **Nacos 连不上 8848**：Nacos 没启动或端口被占；`netstat -ano | findstr 8848` 确认 8848/9848 在监听。
2. **gateway 报 `Port 8080 was already in use` / 「权限不足无法绑定」**：Windows 保留端口段 `8028-8127` 内任何进程都无法绑定，本项目已统一改为 **8000**；如仍报错，确认是从改后的 `bootstrap.yml` 打包启动。
3. **gateway 日志反复刷 Sentinel `127.0.0.1:8718` 连接错误**：本机未装 Sentinel 控制台；`bootstrap.yml` 中 `eager: true` 导致，**不影响功能**，可忽略。
4. **登录报验证码/Redis 相关错误**：确认本机 Redis 6379 已启动，且 Nacos 里 `redis.host` 为 `localhost`。
5. **中文乱码**：连接串已带 `characterEncoding=utf8`；导入 SQL 时务必加 `--default-character-set=utf8mb4`。
6. **文件上传失败**：检查 `ruoyi-file-dev.yml` 的 `file.path`（默认 `D:/ruoyi/uploadPath`，需有写权限），确认文件服务 http://localhost:9300 可通。
7. **IDEA 下 Lombok 报错**：按第五节第 2 步开启注解处理。
8. **改 Nacos 配置不生效**：确认控制台 group=`DEFAULT_GROUP`；必要时重启对应服务。
9. **登录提示「用户密码不在指定范围」**：RuoYi 密码复杂度要求 5~20 位；演示账号 `admin/admin123` 可直接用。接口/脚本登录时直接传明文（登录接口为明文 + RSA 可选），不用走「记住我」cookie。
10. **ERP 某服务 500 / 网关报 JWT 错误**：多为登录 token 失效或网关缓存了旧实例；重新登录；改动网关/Nacos 配置后建议重启网关。
